Today, Cohesity is introducing Cohesity Agent Resilience , a new capability in Cohesity Data Cloud that helps organizations protect agent state and recover AI agents to a trusted version when something goes wrong. AI agents are changing enterprise operations. Unlike AI assistants that help people complete tasks, enterprise AI agents execute multi-step workflows without a human reviewing every step—building memory and context with every interaction.
